# Design and development

## Signals of a good project

- solid code conventions
- good architecture
- testing strategy
- clear project vision and specs
    - what problems the project aims to solve
    - features (specs) clearly laid out in logical parts

## Glossary

- PRD: Product Requirements Document

## Process

x) write a top-level PRD describing the project
x) write more specific PRDs describing each feature 
x) use /grill-me to analyze and align PRDs

## Use agents and skills 

Use agents and skills to create documents for each phase of the development. Review the documents and ask the AI to modify parts that are not aligned with your ideas.


## Grill me

- use /grill-me skill (or similar skill) to question user's specs and intentions. Find flaws and issues. Make user explain reasonings and decisions. Come up with a mutual image of how things should be done.
